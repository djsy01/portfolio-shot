# portfolio-shot 위키

**portfolio-shot**은 개발자 포트폴리오용 스크린샷을 자동으로 촬영하고, 최적화하고, 저장해줍니다 — 페이지마다 일일이 열어서 스크린샷 찍고, 크기 조정하고, WebP로 변환하는 수작업이 필요 없습니다.

이 위키는 좀 더 긴 문서를 담고 있습니다. 빠른 개요, 설치 방법, 전체 설정 표는 [README](https://github.com/djsy01/portfolio-shot/blob/main/README.ko.md)를 먼저 확인하세요 — 여기 있는 페이지들은 더 깊이 다룹니다.

## 페이지 목록

- **[시작하기](Getting-Started-ko)** — 설치, `init`, 첫 `generate` 실행, 프로젝트 구조
- **[설정 옵션](Configuration-Reference-ko)** — 모든 설정 필드와 예제
- **[CLI 명령어](CLI-Reference-ko)** — 모든 명령어와 플래그
- **[트러블슈팅](Troubleshooting-ko)** — 자주 발생하는 에러와 해결 방법
- **[로드맵](Roadmap-ko)** — 이미 나온 기능과 앞으로 계획된 기능 (v1.0 → v3.0)
